## Avitech Sequoia 4K60 & 4K60L

This module supports both the Sequoia 4K60 and 4K60L controls for the companion app. Select which machine you will be using when connecting in order for the Connector to send the correct HTTP commands to your unit.

## Getting started

To connect to your (primary) machine(s), input your machines IP address (Default 192.168.0.5), and (if using the 4K60L) the number of machines being cascaded or daisy chained into the config on installation via Connectors. You can then configure buttons with HTTP commands from the available list depending on the machine you are using.
